# علي بابا V5 — Free Launch

نسخة مخصصة لإطلاق المنصة وتجربتها مع الناس بأقل تكلفة ممكنة.

## ما يعمل في V5
- واجهة عربية RTL ومتجاوبة باسم **علي بابا**.
- تسجيل ودخول وحسابات مستخدمين.
- Google Login اختياري.
- نشر الخدمات/الشغل، بحث وتصنيفات.
- مفضلة، اهتمام، عروض أسعار.
- شات بين العميل والبائع + عداد رسائل غير مقروءة.
- إشعارات.
- تقييمات.
- طلبات ودورة تنفيذ.
- نزاعات وبلاغات.
- بروفايل وإحصائيات وعدد المستخدمين.
- لوحة إدارة للمستخدمين والبلاغات والتحقق.
- توثيق يدوي للهوية (بطاقة + Selfie) مع فحص أولي؛ **AI غير مفعّل في وضع الإطلاق المجاني**.
- حماية CSRF، Secure Cookies، Security Headers، وحد أقصى لحجم الملفات.
- PostgreSQL migrations تلقائية.
- `/health` لمراقبة الخدمة.

## وضع الإطلاق المجاني
`FREE_LAUNCH_MODE=1` هو الوضع الافتراضي في V5.

في هذا الوضع:
- لا توجد مكالمات مدفوعة إلى AI.
- لا يوجد دفع تجريبي ظاهر للعامة.
- Google Login اختياري.
- لا توجد عمولة أو اشتراك داخل المنصة.

> ملاحظة: "مجاني" يعتمد على Free Tier الذي تختاره لخدمات الاستضافة وقاعدة البيانات. بعض الخدمات تغيّر حدود الخطط المجانية بمرور الوقت، لذلك راجع صفحة التسعير قبل الاعتماد عليها.

## أسرع طريقة للنشر

### 1) GitHub
ارفع محتويات هذا المشروع إلى Repository جديد، ولا ترفع ملف `.env` أو أي مفاتيح سرية.

### 2) قاعدة البيانات
التطبيق يحتاج PostgreSQL. إذا كان هدفك عدم دفع أي مبلغ، استخدم مزود PostgreSQL لديه Free Tier متاح لحسابك، ثم ضع `DATABASE_URL` في إعدادات الاستضافة.

### 3) الاستضافة
أنشئ Web Service على مزود لديه Free Tier متاح، واربطه بـ GitHub.

أمر التشغيل:
```bash
gunicorn app:app --bind 0.0.0.0:$PORT --workers 2 --threads 2 --timeout 120 --access-logfile - --error-logfile -
```

### 4) متغيرات البيئة المطلوبة
```text
FREE_LAUNCH_MODE=1
SECRET_KEY=<قيمة عشوائية طويلة وثابتة>
DATABASE_URL=<رابط PostgreSQL>
SESSION_COOKIE_SECURE=1
ADMIN_EMAILS=<إيميل الإدارة>
```

### 5) بعد التشغيل
افتح:
```text
/health
```
ويجب أن تظهر حالة الخدمة وقاعدة البيانات سليمة.

## Google Login — اختياري
يمكنك ترك Google فارغًا والاعتماد على التسجيل العادي. إذا أردته، أنشئ OAuth Client وأضف:
- `GOOGLE_CLIENT_ID`
- `GOOGLE_CLIENT_SECRET`
- `GOOGLE_REDIRECT_URI=https://YOUR-DOMAIN/auth/google/callback`

## التحقق بالبطاقة وSelfie
التوثيق اليدوي موجود، لكن V5 لا تعتمد على AI مدفوع في الإطلاق المجاني. لا تجعل الذكاء الاصطناعي وحده يقرر أن الشخص هو صاحب الهوية.

لإطلاق KYC حقيقي لاحقًا استخدم مزود هوية متخصص يدعم document verification + liveness + face match، مع سياسة خصوصية وموافقة واضحة ومدة احتفاظ محدودة بالبيانات.

## الدفع
الدفع الحقيقي غير مفعّل في V5. هذا مقصود حتى لا تحتاج إلى حساب بوابة دفع أو تتحمل رسومًا أثناء التجربة.

**لا تفعل `ENABLE_DEMO_PAYMENTS=1` على موقع عام.**

## قبل فتح التسجيل للعامة
1. غيّر `SECRET_KEY` إلى قيمة عشوائية ثابتة.
2. ضع بريدك في `ADMIN_EMAILS`.
3. اختبر التسجيل، نشر شغلة، الشات، العرض، الطلب، التقييم، البلاغ، وتعليق الحساب.
4. فعّل HTTPS.
5. اعمل Backup لقاعدة البيانات.
6. راقب `/health` والـlogs.
7. ضع سياسة خصوصية وشروط استخدام واضحة، خصوصًا إذا ستجمع بطاقات هوية وصورًا شخصية.
8. لا تضع أي API key داخل GitHub.
